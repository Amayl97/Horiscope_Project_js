# 🔮 Horoscope Fortune Teller

A tiny JavaScript project that matches a birth month with a zodiac sign and gives you a **random fortune**. ✨

### 🌙 What I practiced

* `if / else if` conditions
* Arrays
* `Math.random()`
* Template literals
* String comparisons

> ✨ Pick a month, check your sign, and see what the universe has in store for you. ♡
